## Дашборды 

В репозитории представлены файлы с контекстом, ссылками и скриншотами дашбордов.

### Coffee Sales Dashboard

— аналитический Excel-дашборд для анализа продаж кофе. Проект включает интерактивный Dashboard с временной динамикой продаж, анализом продаж по странам и клиентам, а также фильтрами по периоду, степени обжарки, размеру упаковки и карте лояльности. Данные предварительно обработаны на отдельных листах книги и используются как источник для построения визуализаций и аналитики.
